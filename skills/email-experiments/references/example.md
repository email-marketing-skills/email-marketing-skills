# Small-sample example

Campaign A: 20 unique delivered contacts, two qualified replies. Campaign B: 20 unique delivered contacts, three qualified replies. Descriptive rates are 10% and 15%; that difference alone is not evidence that B is better.

Inspect whether the audiences and observation windows match. One additional reply can change the apparent ranking. Report the counts and uncertainty, then gather qualitative feedback or plan an adequately sized test using actual baseline assumptions. Do not write “B increased conversion 50%” as a causal result.

If there are zero delivered contacts, a reply-rate denominator is unavailable. If delivery status is missing, do not silently use sent messages instead. For a holdout, define the same outcome window in both groups and keep other interventions comparable.
