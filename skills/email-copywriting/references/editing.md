# Editing checklist and example

Read the message aloud once. Remove sentences that do not help the reader act or understand the offer. Check that the opening still makes sense if the recipient reads no other message in the sequence.

Weak: “Unlock powerful insights with our revolutionary dashboard.”
Better, if true: “Upload your CSV to create the first report. Start with the sample file if your own data is not ready.”

Weak outbound: “Your agency is wasting hours on reports.”
Better, if sourced: “Your services page includes monthly client reports. Would a sample report using dummy data be useful to compare with your current format?”

The second version still needs real sender details and the appropriate opt-out content before delivery. It does not claim the recipient has a problem. Examples teach structure, not a reusable factual claim.

A subject variant is a hypothesis, not a predicted winner. Change one meaningful variable at a time. If the audience is too small to learn from a split, inspect replies and task completion instead.
