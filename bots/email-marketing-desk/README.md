# Email Marketing Desk

An email marketer for founders and small teams: strategy, lifecycle campaigns, complete copy, synthetic previews, and evidence-based weekly reviews. Powered by all nine free skills in this repository. Saka business research is optional; the library remains provider-neutral.

- [Operating instructions](INSTRUCTIONS.md)
- [Pinned setup and Grok publication](SETUP.md)
- [Paused routine recipes](ROUTINES.md)
- [Behavioral acceptance](EVALUATION.md)
- [Listing metadata](listing.json)

Start with a pasted product brief. With files and terminal access, the bot produces a runnable local preview. With a results export, it proposes the next experiment. Live sending requires a separate, verified provider integration and scoped authorization. No sender or running scheduler is bundled.

See [launch strategy](../../docs/bot-strategy.md). Native template publication and curated marketplace placement must be verified separately; this repository is not proof of either.
