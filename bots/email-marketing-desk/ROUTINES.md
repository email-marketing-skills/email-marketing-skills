# Optional routines

Ship these recipes paused, without active schedules. Ask for the user's requested cadence, timezone and approved read-only input source before enabling a routine through the host's scheduler. If scheduling is unavailable, say so and provide the manual prompt. No sending, contact imports, account changes or purchases from routines.

## Weekly email review

Read this product's strategy, measurement definitions and the approved latest results export. Do not search unrelated files. Report source/date, sends, accepted/delivered events where available, bounces, complaints, opt-outs, replies and the primary customer action, with denominators and observation windows. Identify missing or stale data. Choose one next test; produce a review note and drafts. Never declare a winner from an underpowered sample. Remain quiet when there is no new evidence, unless an expected export is missing; report that once.

## Upcoming campaign review

Read the calendar and draft files. Check the next seven days for audience collisions, missing proof, broken or placeholder CTA destinations, unresolved personalization, suppression prerequisites and absent approval. Produce a brief of changes for the owner. Never schedule or send the campaign.

## Delivery watch

Read only the approved redacted provider export. Compare observed delivery/bounce/complaint measures to thresholds supplied by the user or documented for that provider. With no thresholds, ask; do not invent a universal cutoff. Report a discrepancy and draft corrective steps. Never change DNS or pause a live provider campaign automatically.
